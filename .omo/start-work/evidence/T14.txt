[5] BUG FOUND AND FIXED BEFORE FINALIZING (disclosed for reproducibility)
The first full run's marginal (player, rank) one-vs-rest indicators were built with an
overwrite bug: `y_cells[:, player, perm[player]] = (true_idx == k)` inside the loop over k,
so each cell kept the indicator of one arbitrary permutation (frequency ~0.042 per cell
instead of 0.25). Fixed to accumulate over permutations and added an assert
`abs(y_cells.mean() - 0.25) < 1e-9`. Re-ran the full audit (run2); only `marginal_*` numbers
changed (corrected values: marginal_ovr_ece 0.0066 / marginal_ovr_brier 0.1547; pre-fix
0.2083 / 0.1036); top-1, pooled-OvR, probe, Q and value metrics were unaffected (bit-identical
headline: 0.0099 / 0.0242 / 0.0364). Pre-fix results kept at
/tmp/opencode/a2b/results_pre_fix.json for audit. PREREG.md was not modified.

[5b] PREREG DEVIATION CAUGHT AND CLOSED (before the commit)
