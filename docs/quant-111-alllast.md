## 1. 数据范围

- 2004 局中 **1576 局到 all-last**（`bakaze=="S" && kyoku==4`），428 局提前终局（トビ）不计入指标；重放失配 0、文件名与种子失配 0。
- 1576 局里 **71 局进入西入**（W1 到 W4）：这些局的牌谱末局不是 S4 局。脚本两种口径都产出。本报告**主引终局口径**（牌谱末局 + 终局供托按 `arena/game.rs:182-184` 补给最高分者），并给出 **at-S4-end 口径**（最后一个 S4 局结束时）的对应值。

## 2. 指标 (a)：all-last 结束时的分差分布（终局口径）

| 目标 | 与第 1 名分差 p25 / p50 / p75 / p90 |
|---|---|
| 第 2 名 | 4,800 / **9,500** / 16,925 / 25,500 |
| 第 3 名 | 12,200 / **18,900** / 26,825 / 35,950 |
| 第 4 名 | 21,600 / **30,100** / 38,425 / 47,050 |

- 相邻 3rd-4th：p25 / p50 / p75 = 4,000 / **9,000** / 15,125；**45.1%**（711/1576）的局 3rd-4th 分差小于 1 満貫（8,000 点），24.0%（378/1576）小于 3,900。
- 4th 与 1st 分差小于 8,000 仅 **4/1576 = 0.25%**（小于 3,900 为 0）。"超车"现实上是对第 3 名，不是对第 1 名。
- at-S4-end 口径对应值：p50 2nd=9,100 / 3rd=18,800 / 4th=30,000；相邻 3rd-4th p50=8,900；4th 与 1st 小于 8,000 为 28/1576 = 1.78%。

## 3. 指标 (b)：第 4 名和了末局、但仍第 4 的比例

- **终局口径：27/159 = 17.0%**（JSON `fraction_winner_was_4th_still_4th = 0.169811`）。第 4 名赢下末局的 159 局里，83.0% 成功变位，17.0% "赢了仍是第 4"。
- **at-S4-end 口径：37/181 = 20.4%**（0.204420）。相比终局口径，分子多 10、分母多 22，差额全部来自西入的 71 局。
- 参考面：第 4 名赢下末局共 159 次 = 10.1% 的 all-last 局（末局和了 1504 局、流局 72 局）；赛前第 4 名最终仍第 4 的整体比例 = 1368/1576 = 86.8%。

## 4. 分组差异

- 按 `by_filename_key`：主语料 key `579411421376059130` 1574 局，指标 (b) 27/159；4 个 legacy akochan 文件 key `423244137402621143` 仅 2 局、(b) 分母 0。指标结论完全由主语料驱动。
- 按 `by_split`（挑战者座位 a/b/c/d）：n = 396/400/394/386；指标 (b) = 5/36=13.9%、7/40=17.5%、9/51=17.6%、6/32=18.8%；3rd-4th p50 = 8,950/9,700/9,250/8,400。座位间无单调模式，且分母只有 32 至 51，差异不具解释力。
- 按 `by_names`：四种 `mortal|old148800|...` 座位排列分别 396/399/393/386 局，另 2 局含 `akochan`（该字段只存计数）。

## 5. 量级结论

- 异常存在但不大：**1.71%** 的 all-last 局（27/1576）出现"末局和了者赢了仍第 4"；但在"第 4 名赢末局"这个子集里失败率达 17.0%，不是边缘噪声。
- 临界决策面很宽：**45.1%** 的 all-last 局 3rd-4th 分差小于 1 満貫（8,000），这正是 #111 说的、翻盘线取决于"谁付钱 / 多大牌"的离散刻度区。
- 结论：#111 是一个常驻、可测、但单独不足以构成重训理由的误差面。是否并入下一次本来计划的重训，见路线图 A.4 的决定；本报告只给数，不代拍。
