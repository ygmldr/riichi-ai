## 1. What was implemented

1. **`riichiformer/data/replay.py`** — read-only native replay adapter:
   - `GameplayLoader(4, oracle=False).load_log(raw)` is the sole rule authority (skeleton: pinned
     submodule, no Python rules reimplementation);
   - per seat returns actions, 46-wide masks, kyoku/turn indices and validates **every** logged action
     against `mask[action]`; illegal/mismatched decisions are recorded with decision index, action,
     legal_count, kyoku and turn (never repaired, never re-indexed);
   - rejects mask width ≠ 46, action/mask length mismatch, non-4-seat output, bad JSON;
   - `final_scores_from_events()` mirrors `eval_report.py`: `start_kyoku.scores` authoritative,
     `reach_accepted` deducts 1000 into kyotaku, `hora`/`ryukyoku` deltas, kyotaku to the first winner.
2. **`scripts/rf_validate_replays.py`** — reads a manifest (audit/canonical Parquet), deterministic
   stratified sample (or `--all`), thread pool, writes `replay_report.json` + `invalid_games.jsonl`
   with error kinds, yearly denominators, decision counts; exit 0 only when every sampled action is legal.
3. **`tests/rf_test_replay.py`** — 6 tests: score/kyotaku accounting, ryukyoku/next-kyoku authority,
   no-kyoku case, real-game replay (all actions legal), mask width 46, bad-JSON error path.

## 5. Risks / limitations

- **Sample only**: 1,000 of 2,512,424 games. A full streaming run is required before claiming 100%
  legal rates; the card's PASS asks for 1,000 stratified smoke **plus** a full report, so this PR is a
  documented partial gate.
- `oracle=False`: invisible observations were not computed (they are irrelevant to action/mask parity but
  will be needed for training data). POV redaction/censored labels are PR-09/PR-10, not proven here.
- Native loader accepted all 1,000 logs; this does **not** mean every local log is valid (2.5M).
- Double-ron and other rare priority cases are not separately constructed; engine IDs are trusted as the
  authority but a dedicated fixture is still required by PR-10/PR-16.
- Rights remain `unknown`; replay validation does not authorise training.
