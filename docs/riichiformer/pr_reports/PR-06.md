## 1. What was implemented

1. **`riichiformer/data/player_quality.py`**
   - HMAC-SHA256 player ids from `start_game.names`; requires `RF_PLAYER_HMAC_KEY` (≥16 bytes),
     otherwise no player-linked audit (basic game audit still allowed);
   - Tenhou filename timestamp `YYYYMMDDHH` → naive match time (ordering only);
   - 1-based ranks with stable seat tie-break (same convention as `eval_report.py`);
   - empirical-Bayes `q = (n*mean_rank + k*prior)/(n+k)`, defaults `prior=2.5`, `k=100`,
     history strictly earlier and **inside the allowed train game set**, target game excluded;
   - missing timestamps → full allowed pool and `temporal=false`; `n<50` → `insufficient_history`
     + `confidence=n/(n+k)`; target rank kept only as `target_rank_for_eval`;
   - `top25_seat` = eligible players in the best 25% of q; never inferred for the other three seats;
   - `reliability_table`: each player's last appearance (q from prior games vs that game's rank);
   - `assert_no_names` guard; public rows contain HMAC only.
2. **`scripts/rf_quality.py`** — reads only the split manifest's `train` rows, deterministic stratified
   sample, thread-pooled parsing; emits `quality_scores.parquet` (HMAC-only), `quality_summary.json`,
   `quality_audit.md`; basic mode (no key) writes zero player rows and no names.
3. **`tests/rf_test_quality.py`** — 14 tests: key required/strength, HMAC determinism, future results
   cannot change a target score, target's own rank not used, one-game low confidence, `n==50` boundary,
   forbidden (val) games excluded from history, non-temporal fallback, TOP25 does not mark other seats,
   rank/tie parsing, name-leak guard, invalid names, CLI basic + linked modes.

## 5. Risks / limitations

- **Sample-limited**, not full corpus: history only contains the 100k sampled train games; the
  56.89% insufficient rate is therefore inflated (full corpus would give more history).
- **No metadata**: local logs have names only; no dan/R/rating/date-at-game, no annual DB.
  All such fields are `null/unknown`; nothing was inferred from names.
- **No AI-account inference**; absence of evidence is `unknown`, never `confirmed_human`.
- **No demonstrated predictive validity** (INCONCLUSIVE); `q`/`top25` cannot be used as a certified
  quality label. Any use needs a preregistered experiment and a different (larger) history corpus.
- **HMAC key is ephemeral**: scores are keyed by HMACs that cannot be joined across runs without the
  secret; this is intentional, but means the artefact is not independently reproducible.
- Target rank is stored for evaluation only; code/test guarantee it never enters q. Validation/select/
  confirm games are excluded from history by manifest filter (`train` only).
- 100k games were all `tenhou_old` (2009–2022) because the stratified sample of L-train covers those
  years; `tenhou_recent` quality is not yet sampled.
