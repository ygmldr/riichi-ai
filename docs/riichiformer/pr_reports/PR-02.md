## 1. What was implemented

1. **`riichiformer/schemas/provenance.py`** — source ids / rights enums, year→source mapping,
   `rights_allow_new_training()` (only explicit `allowed`), truthful default registry
   (`tenhou_old`/`tenhou_recent`/`teacher_local`/`selfplay_own` = `unknown`, `majsoul_optional` =
   `restricted`), and block-reason generation.
2. **`riichiformer/data/scan.py`** — streaming audit:
   - magic-byte compression detection (gzip / zip / plain JSON / empty / unknown), independent of extension;
   - year derived only from an explicit year directory or a `20YY…` filename prefix (never from hex suffixes);
   - per-file rows streamed to Parquet (no 2.5 M-row RAM list), per-year aggregation, deterministic
     per-year deep sample (first 200 in sorted traversal);
   - zip audit: `ZipFile.testzip()` validates every member CRC; member counts/bytes recorded; 3 members
     sampled per archive (read in-memory, never extracted);
   - strict NDJSON sample parser (`start_game`/`start_kyoku`/`end_kyoku`/`end_game` required);
   - outputs `source_audit.parquet`, `yearly_counts.csv`, `bad_files.jsonl`, `samples.jsonl`,
     `source_rights.csv`, `audit_summary.json` and `DATA_REPORT.md`.
3. **`scripts/rf_data_audit.py`** — `--roots/--mode scan-only/--out/--report/--sample-per-year/--hash-mode`.
   `EMPTY` is a successful audit but sets `training_blocked=true`; exit 2 only when every root is missing.
4. **`tests/rf_test_scan.py`** — 13 tests: magic detection, extension-independent compression, year
   parsing (incl. the `…-e2011cd6` regression), gzip/plain/corrupt gzip/corrupt zip, duplicate names in
   different dirs, mixed roots, multi-root dir+zip, empty root (success + training blocked), Parquet schema
   and absence of identity columns, rights gating, CLI exit codes.

## 5. Risks / limitations (must not be omitted)

- **Rights**: all Tenhou sources remain `unknown`; new training is blocked even though the audit is clean.
  This is a policy blocker, not a data-quality blocker.
- **Sampling**: magic/size/mtime are 100% measured for every leaf, zip CRC is 100% validated, but full
  JSON parsing is only the 3,654 deep samples (plus PR-04's independent 1,000 native replays). `bad_files=0`
  does **not** prove every one of the 2.5 M logs parses.
- **2026 is partial (January)**; 2009 starts in February. No missing months were fabricated or filled.
- **No identity data** exists locally (no dan/R/date at game time); PR-06 must return `unknown` instead of
  inventing quality labels.
- **`datasets/` extracted is 11.44 GiB**, not the 40–60 GB mentioned in older docs; 1:1 member/file counts
  show it is complete for the current zips, but this must be re-audited if new zips arrive.
- The audit writes only under `artifacts/riichiformer/audit/` and the report; it never touches `datasets/`.
