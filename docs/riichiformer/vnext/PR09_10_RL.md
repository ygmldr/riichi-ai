# PR-09/10 — RL behavior, reward, GAE and toy objectives

**Code**: `riichiformer/vnext/rl.py`
**Tests**: `tests/rf_test_vnext_rl.py` (14 passing, CPU)

## Implemented

* `behavior_probs(raw_logits, legal_mask, GuardSpec)`:
  - illegal mass exactly zero; effective mask respected;
  - temperature, top-p, epsilon mixing and a forced action are real sampling
    transforms;
  - a forced action is probability 1 and marked `forced`;
  - returns the distribution used for the executed action, not a post-hoc
    renormalized raw softmax.
* `RLDecisionRow` stores legal/effective masks, raw logits, full 46 behavior
  probabilities, executed action, `behavior_logprob=log(mu[action])`, guard
  reason, policy/opponent/GRP/rules SHAs, `kyoku_done`, `match_done`.
* `mortal_delta_rewards` and `pbrs_rewards` both telescope to
  `R_final - Phi_0` per seat; `check_no_double_terminal` rejects adding a
  terminal payment to a delta form.
* `two_timescale_gae` uses `lambda_inter` only at kyoku boundaries and never
  bootstraps through a terminal transition.  A hand-computed 3-step terminal
  case yields `[9,8,7]`.
* `awr_loss` uses `exp(A/beta)` with a finite weight clip and optional reverse-KL
  to a reference; `ppo_loss` is the clipped ratio objective.
* `LeagueManifest` fixes the default 1 learner + 3 frozen opponent checkpoint
  SHAs and version.
* `PR-10` is represented only by these CPU toy objectives and the league
  contract.  No native league or learner loop is claimed.
