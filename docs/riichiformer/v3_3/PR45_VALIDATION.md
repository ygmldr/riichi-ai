**Frozen metadata field names.** `ShardMetadata` mandates three 64-hex fields
named for the H-02 pipeline. A self-play corpus has no canonical/split manifest,
so they carry explicit corpus derivations (documented in
`SELFPLAY_HASH_DERIVATION` and asserted in tests):

* `canonical_manifest_sha256` = SHA-256 of the canonical corpus manifest
  (format, ruleset, window, key, lineup, generator hash, every
  `(game_id, log_sha256)` pair) → `ca0caa17…` (value embedded in the shard);
* `canonical_index_sha256` = SHA-256 of the sorted `[[game_id, log_sha256], …]`
  index;
* `split_manifest_sha256` = SHA-256 of the canonical window descriptor
  `{seed_start, games, seed_key, ruleset_id, lineup, generator_sha256}`.

`data/shard.py`, `data/loader.py` and `selfplay/rollout.py` were **not modified**.

## 4. Read-only validation reader (training foreclosed)

Two independent gates:

1. `ShardReader(path, purpose="train")` on this shard raises
   `ShardRightsError` because the metadata purpose is `diagnostic` (asserted in
   `test_training_loader_refuses_diagnostic_shard` and in the PR-47 roundtrip:
   `training_loader_refusal=ShardRightsError`).
2. `ValidationReader` opens `ShardReader(..., purpose="diagnostic")` only and
   additionally refuses a shard whose `purpose` is `train`, whose
   `train_eligible_under_policy` is true, or that carries a `split="train"` game
   row. It exposes:
   * `iter_forward_inputs()` → only `MultiDecisionBatch` tensors (no target
     objects);
   * `iter_batches()` → forward batch + immutable (`MappingProxyType`) target
     mappings + public context;
   * `evaluate(model)` → `torch.no_grad()` + `model.eval()`, asserts that no
     parameter gradient was produced, and restores the previous mode;
   * `optimizer_update_forbidden()` → explicit refusal (there is no optimizer
     argument anywhere in the class).

The reader also re-hashes every stored input/target row
(`verify_shard_integrity`) because the training loader does not. On this corpus:
73,841 inputs and 73,841 targets, **0 input-hash mismatches, 0 target-hash
mismatches, 0 orphan targets, `ok=true`**.

### 5.1 What the numbers mean (and do not)

* CE/NLL are natural-log imitation losses over supervised, legal, non-censored
  decisions only. `ce == nll`.
* `top1`/`top3` use strict ranking against the native legal mask: an action is
  top-k only if fewer than k legal actions score strictly higher.
* The corpus was generated by **weak local heuristic bots**. A low CE would mean
  "imitates weak bots", not strength; an arena (PR-46) is required for strength.
  No Tenhou/dan/rank claim is made or implied.
* Phase buckets are an exclusive partition and sum to the supervised total;
  scenario slices overlap and are explicitly marked `overlap_is_exclusive=false`.

### 5.2 Prefix vs multi-decision parity

Same model instance and seed through `Policy.forward` (one prefix per decision)
and `Policy.forward_multi` (shared stream + markers) on a 64-decision fixture:
**logits max abs 4.17e-07** on the 8-decision pytest smoke and
**7.152557e-07** on the full 64-decision run (log-prob max abs 0.0 and 0.0;
loss max abs 4.768372e-07), all within the 1e-5 tolerance. This is a correctness fixture only; no throughput or strength
claim is derived from it.
