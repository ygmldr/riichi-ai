## 1. Arm definition (A8, the event-branch-only arm)

A8 reuses the **E3a architecture verbatim** — CNN c=192/40 blocks **plus** the residual zero-init
event Transformer (`[model] use_event_branch=true`, 4 layers, d=128, 4 heads, FFN=512) — and
zeroes the CNN embedding `phi` *immediately before* the residual fusion, so the fused value is
`phi_out = 0 + W_zero(h_event)`: the model's only path to the classifier is the event branch
(the roadmap's "Transformer-only"/E3b role, realised on the E3a skeleton).

Mechanism (`scripts/exp_a8_phi_zero.py`, launcher-level, **no vendor patch**):

- `Brain.__init__` is wrapped so every **branch-enabled** Brain gets a forward hook on
  `Brain.encoder`. The hook returns `torch.zeros_like(encoder_output)`; `Brain.forward` reads
  that return value at `phi = self.encoder(obs)`, whose very next statement is the fusion
  `phi = phi + self.event_branch(events)`. So the fusion input `phi` is exactly zero.
- The hook asserts on **every** call that the returned tensor is all-zero, counts calls, and
  records `max|phi_before_zero|` (proving the discarded CNN embedding was genuinely non-zero,
  i.e. the test is not vacuous), writing `runs/exp/A8/phi_zero_proof_{train,eval}.json` at exit.
- Branch-less Brains (e.g. the pinned champion inside A8's eval) are deliberately **not** hooked;
  branch enabled + `events=None` still raises (the patch-0007 guard is untouched), so a silently
  branch-less A8 run cannot complete.
- `assert_armed()` runs after `main()`: `hooked_brains >= 1 and calls > 0` is mandatory — an A8
  that silently evaluated as E3a would be a false negative.

Self-check (`scripts/exp_a8_selfcheck.py` → `runs/exp/A8/selfcheck.json`, CPU, before training):
parameter total **11,818,752** (= E3a exactly; encoder 10,787,456 + branch 1,031,296);
hooked output equals `actv(W_zero(h_event))` with maxdiff **0.0**; with two different `obs` and
the same `events` the hooked output is **bit-identical** (maxdiff 0.0) while an un-hooked control
moves (0.0105); after one backward, **407/407 encoder parameters have no gradient** and
`proj.weight.grad` norm = 337.7 (the event branch trains, the CNN does not); `events=None` still
raises the 0007 guard. An end-to-end 4-game smoke of the *eval* launcher (seed 40000, /tmp only)
also passed: hook armed, 506 challenger forwards zeroed, `MORTAL_EVT_DEBUG` feed assertions pass.

## 2. Training protocol (declared BEFORE launch)

- **Step budget: 20,000 optimizer steps** — identical to E2/E3a (batch 1024, `opt_step_every=1`,
  20.48 M samples), from scratch. A8's checkpoint's own config carries
  `use_event_branch=true`, so eval rebuilds the same architecture (and re-applies the hook).
- Config `runs/exp/A8/train.toml`, generated by `scripts/exp_a7a8_make_configs.py` **from E3a's
  `train.toml`** by path rewrite only; condition-match diff vs E3a = paths only, all other keys
  bit-identical (printed by the generator). `[model]` stays E3a's (toggle=true, d=128/4/4/512).
- Conditions matched to E3a: `batch_size=1024`, `opt_step_every=1`, `save_every=2000`,
  `test_every=100000`, `submit_every=400`, `enable_amp=true`, **`enable_compile=false`**,
  `num_workers=3`, dataset globs 2009–2022 + 2023 holdout, `val_batches=20`,
  `file_index=checkpoints/file_index.pth` (read-only), optimizer/scheduler unchanged,
  `freeze_bn.mortal=false`.
- Launch: `scripts/exp_a8_launch.py train` (installs the hook before importing `train.py`;
  re-asserts the config safety paths and `MORTAL_CFG` under `runs/exp/A8/`), watchdog
  `scripts/exp_a7a8_watchdog.py` stops it after the step-20,000 save.
- **Known asymmetry (documented, not hidden)**: A8 still pays the CNN forward compute although
  its output is discarded; it therefore costs the same as E3a per step but its trainable
  function is the branch alone. The CNN's BatchNorm running stats keep updating in train mode
  (irrelevant: they are never read under zeroing).
- **Safety**: all writable paths under `runs/exp/A8/`; `checkpoints/mortal.pth` is never a
  training target; `runs/1v3/*.json.gz` is never written.

## 3. Arm evaluation protocol (pool A, declared BEFORE launch)

- 12,000 games = 3,000 sets, `seed_key = 0x5dfaa4cef265cd7`, **`seed_start = 10000`** (pool A;
  pool B `50000` MUST NOT be consumed here).
- challenger = `runs/exp/A8/state.pth`; champion = `checkpoints/mortal.pth.at-148800`.
- own `log_dir` = `runs/exp/A8/games/`; config `runs/exp/A8/eval.toml`.
- **Event-feed gate (mandatory, todo 18-C mechanism)**: the eval runs with
  `MORTAL_EVT_DEBUG=<path>`; afterwards `scripts/exp_e3a_check_feed.py` (reused read-only)
  asserts every engine-evaluated decision received a non-empty token stream (`n >= 1`, first
  token `start_kyoku`, last token a valid event type) and writes
  `runs/exp/A8/EVAL_FEED_A8.json`. Because a branch-enabled Brain raises on `events=None`, a
  branch-less A8 eval cannot complete at all; the debug stream makes the feed observable. In
  addition, `phi_zero_proof_eval.json` records the number of zeroed A8 forwards during the eval.
- Report: `scripts/eval_report.py --games-dir runs/exp/A8/games --seed-key
  0x5dfaa4cef265cd7 --seed-range 10000-13000 --checkpoint state.pth --source-dir runs/exp/A8
  --out runs/exp/A8/report.csv`.
- **Resolution context**: 12 k games ⇒ 80 %-power MDD ≈ **0.0239 avg_rank / 1.86 pt**
  (`runs/variance/README.md`). Effects below that are *not* evidence of no effect.
- **Interpretation**: pool A feeds the five-arm ranking (todo 22) only; the verdict is E3a vs E2
  on pool B. Expected, per the plan's QA: if A8's loss is completely flat it is recorded as
  "A8 untrainable" (a valid result). Note `W_zero` is zero-initialised, so at step 0 the output
  is input-independent (constant `actv(0)`); the first backward immediately breaks that symmetry
  (selfcheck: `proj.weight.grad` norm 337.7), so a flat loss would be a real finding, not an
  artefact.
